01 / Décider avant de coder

Seule la première réponse compte.

À la page précédente, le joueur pouvait changer de réponse avant de passer à la suivante. Pour compter les points, nous changeons volontairement cette règle :

  1. Une bonne première réponse rapporte un point.
  2. Une mauvaise première réponse rapporte zéro point.
  3. Après ce premier choix, les boutons de réponse sont désactivés. Le résultat ne peut plus être changé pour cette question.
  4. « Question suivante » permet toujours d’avancer après une réponse, correcte ou incorrecte.

Pour quatre questions, le score final est compris entre 0 et 4. Nous ne retirons pas de point et il n’y a pas de temps limite dans cet exercice.

Avec l’encadrant, garde la version précédente dans Git puis prépare une branche comme ab/ajouter_score_et_recommencer.

💡

Score

Le nombre de points obtenus. Dans cette version, il correspond au nombre de bonnes premières réponses.

💡

Règle de comptage

Le choix qui définit quand un point est gagné. Elle doit être comprise avant de modifier le code.

02 / Garder le contrôle de la règle

Le presenter compte, la vue demande.

Le score est une propriété privée du presenter, parce que la vue ne doit pas pouvoir lui ajouter directement des points :

private var score: Int = 0

fun getScore(): Int {
    return score
}

Le drapeau hasAnsweredCurrentQuestion existe déjà. Il sert maintenant aussi à empêcher de compter plusieurs réponses pour la même question. Une nouvelle propriété conserve le résultat de la première réponse :

private var isCurrentAnswerCorrect: Boolean = false

Dans submitAnswer, avant de refaire le calcul :

if (hasAnsweredCurrentQuestion) {
    return isCurrentAnswerCorrect
}

Si une réponse est déjà enregistrée, l’action renvoie le résultat précédent sans changer le score. Sinon, elle vérifie le choix, conserve ce résultat et ajoute un point si nécessaire.

QuizPresenter.kt complet
package fr.stageacademy.quiz

class QuizPresenter(private val questions: List<Question>) {
    private var currentQuestionIndex: Int = 0
    private var hasAnsweredCurrentQuestion: Boolean = false
    private var isCurrentAnswerCorrect: Boolean = false
    private var score: Int = 0

    fun getScore(): Int {
        return score
    }

    fun getCurrentQuestionIndex(): Int {
        return currentQuestionIndex
    }

    fun isFinished(): Boolean {
        return currentQuestionIndex >= questions.size
    }

    fun getCurrentQuestion(): Question {
        return questions[currentQuestionIndex]
    }

    fun isCorrectAnswer(
        question: Question,
        selectedAnswer: String,
    ): Boolean {
        val result: Boolean = selectedAnswer == question.correctAnswer
        return result
    }

    fun submitAnswer(selectedAnswer: String): Boolean {
        if (isFinished()) {
            return false
        }
        if (hasAnsweredCurrentQuestion) {
            return isCurrentAnswerCorrect
        }
        val question: Question = getCurrentQuestion()
        isCurrentAnswerCorrect = isCorrectAnswer(question, selectedAnswer)
        hasAnsweredCurrentQuestion = true
        if (isCurrentAnswerCorrect) {
            score = score + 1
        }
        return isCurrentAnswerCorrect
    }

    fun canGoToNextQuestion(): Boolean {
        return hasAnsweredCurrentQuestion
    }

    fun goToNextQuestion(): Unit {
        if (canGoToNextQuestion()) {
            currentQuestionIndex = currentQuestionIndex + 1
            hasAnsweredCurrentQuestion = false
            isCurrentAnswerCorrect = false
        }
    }

    fun restart(): Unit {
        currentQuestionIndex = 0
        hasAnsweredCurrentQuestion = false
        isCurrentAnswerCorrect = false
        score = 0
    }
}

Le passage à la question suivante remet les deux informations de réponse à false, mais conserve le score. L’action restart remet aussi le score et l’indice à zéro.

La protection doit exister dans le presenter.

Désactiver un bouton améliore l’usage, mais la règle doit rester correcte si submitAnswer est appelée deux fois. Le presenter refuse de recompter, même si un autre code lui redemande le travail.

💡

Première réponse enregistrée

Le presenter conserve son résultat jusqu’au passage à la question suivante. Un appel supplémentaire ne remplace pas cette réponse.

💡

score = score + 1

Lire le score actuel, lui ajouter un point, puis conserver la nouvelle valeur dans la même variable.

03 / Montrer la règle au joueur

Désactive les choix après la réponse.

Dans QuestionView, les boutons de choix deviennent :

Button(
    onClick = { checkAnswer(choice) },
    enabled = !canGoToNextQuestion,
) {
    Text(text = choice)
}

Au départ, canGoToNextQuestion vaut false : les choix sont donc activés. Après une réponse, cette valeur devient true : les choix se désactivent et « Question suivante » s’active.

Le signe ! inverse un Boolean : « pas ». !false donne true et !true donne false. Nous utilisons ici l’inverse de l’autorisation d’avancer pour savoir si l’on peut encore répondre.

Le message ne dit plus au joueur de réessayer sur la même question. Garde « Bonne réponse ! » pour une réponse correcte et remplace le message incorrect par « Réponse incorrecte. ».

💡

Inverser · negate

Transformer vrai en faux, ou faux en vrai. En Kotlin, ! se place devant le Boolean.

💡

enabled · activé

Une information d’affichage et d’interaction. Le presenter applique aussi la règle, indépendamment de l’état du bouton.

04 / Relire le score pour l’affichage

Une nouvelle valeur observée par Compose.

Dans WelcomeScreen, nous ajoutons une valeur d’affichage, initialisée avec le score du presenter :

var displayedScore: Int by remember(presenter) {
    mutableStateOf(presenter.getScore())
}

Le score privé dans le presenter reste la référence pour la règle. displayedScore est sa copie pour l’affichage, relue après l’action. Modifier seulement score dans une classe Kotlin ordinaire ne prévient pas Compose.

QuestionView reçoit donc une action supplémentaire :

onAnswerSubmitted: () -> Unit

Après avoir demandé la validation et mis à jour son message, elle appelle onAnswerSubmitted(). WelcomeScreen fournit cette action :

onAnswerSubmitted = {
    displayedScore = presenter.getScore()
}

Ce n’est pas cette action d’affichage qui ajoute un point : elle ne fait que relire le résultat. Le trajet est clic → submitAnswer → comptage → relecture → affichage.

Le texte du score est :

Text(text = "Score : $displayedScore / ${questions.size}")

Le signe $ insère la valeur dans le texte. La barre / est ici un caractère affiché, pas une division : « Score : 2 / 4 » signifie deux points sur quatre possibles.

💡

displayedScore

« Score affiché » : l’information observée par Compose pour écrire le résultat à l’écran.

💡

onAnswerSubmitted

« Quand une réponse a été envoyée ». Une action transmise pour prévenir l’écran qu’il doit relire le score.

05 / Une nouvelle partie

Remettre tout le déroulement à zéro.

Le bouton « Recommencer » apparaît sur l’écran de fin. Son action demande au presenter :

fun restart(): Unit {
    currentQuestionIndex = 0
    hasAnsweredCurrentQuestion = false
    isCurrentAnswerCorrect = false
    score = 0
}

Puis la vue relit l’indice, le statut de fin et le score. Elle affiche la première question, ses choix activés et le message initial.

On utilise la même instance du presenter. Réinitialiser une partie n’est pas recréer les fichiers, relancer Android Studio ou récupérer les données sur GitHub.

Que se passe-t-il avec une liste vide ?

Le score reste 0, et le quiz est déjà terminé puisque la liste ne contient pas de question. Recommencer ne peut pas inventer une question. Le texte « 0 / 0 » peut être affiché ; aucune division n’est exécutée.

💡

Restart · recommencer

Revenir à l’état initial d’une partie. Il faut réinitialiser toutes les informations concernées, pas seulement le score.

💡

Réinitialiser · reset

Redonner les valeurs de départ : indice 0, aucun choix enregistré et score 0.

06 / Dans les trois fichiers

Garder les liens explicites.

Question.kt ne change pas. Dans QuizPresenter.kt, utilise la version complète donnée plus haut. Dans MainActivity.kt, remplace les deux fonctions de vue par ces versions, en conservant la classe MainActivity, sa prévisualisation et les imports existants.

QuestionView complète
@Composable
fun QuestionView(
    question: Question,
    questionIndex: Int,
    presenter: QuizPresenter,
    onAnswerSubmitted: () -> Unit,
    onNextQuestion: () -> Unit,
) {
    var feedbackText: String by remember(presenter, questionIndex) {
        mutableStateOf("Choisis une réponse.")
    }
    var canGoToNextQuestion: Boolean by remember(presenter, questionIndex) {
        mutableStateOf(presenter.canGoToNextQuestion())
    }

    fun checkAnswer(selectedAnswer: String): Unit {
        val isAnswerCorrect: Boolean = presenter.submitAnswer(selectedAnswer)
        if (isAnswerCorrect) {
            feedbackText = "Bonne réponse !"
        } else {
            feedbackText = "Réponse incorrecte."
        }
        canGoToNextQuestion = presenter.canGoToNextQuestion()
        onAnswerSubmitted()
    }

    Column(
        verticalArrangement = Arrangement.spacedBy(12.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
    ) {
        Text(text = question.text)
        for (choice: String in question.choices) {
            Button(
                onClick = { checkAnswer(choice) },
                enabled = !canGoToNextQuestion,
            ) {
                Text(text = choice)
            }
        }
        Text(text = feedbackText)
        Button(
            onClick = onNextQuestion,
            enabled = canGoToNextQuestion,
        ) {
            Text(text = "Question suivante")
        }
    }
}
WelcomeScreen complet
@Composable
fun WelcomeScreen(modifier: Modifier = Modifier) {
    val firstQuestion: Question = Question(
        text = "Quel outil garde l’historique du code ?",
        choices = listOf("Git", "Android", "Compose"),
        correctAnswer = "Git",
    )

    val secondQuestion: Question = Question(
        text = "Quel composant Compose affiche du texte ?",
        choices = listOf("Button", "Text", "Column"),
        correctAnswer = "Text",
    )

    val thirdQuestion: Question = Question(
        text = "Quel mot-clé déclare une fonction en Kotlin ?",
        choices = listOf("fun", "val", "if"),
        correctAnswer = "fun",
    )

    val fourthQuestion: Question = Question(
        text = "Quel type représente vrai ou faux ?",
        choices = listOf("String", "Boolean", "Int"),
        correctAnswer = "Boolean",
    )

    val questions: List<Question> = listOf(
        firstQuestion,
        secondQuestion,
        thirdQuestion,
        fourthQuestion,
    )
    val presenter: QuizPresenter = remember(questions) { QuizPresenter(questions) }
    var displayedQuestionIndex: Int by remember(presenter) {
        mutableStateOf(presenter.getCurrentQuestionIndex())
    }
    var isQuizFinished: Boolean by remember(presenter) {
        mutableStateOf(presenter.isFinished())
    }
    var displayedScore: Int by remember(presenter) {
        mutableStateOf(presenter.getScore())
    }

    Column(
        modifier = modifier
            .fillMaxSize()
            .verticalScroll(rememberScrollState())
            .padding(24.dp),
        verticalArrangement = Arrangement.spacedBy(24.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
    ) {
        Text(
            text = stringResource(R.string.welcome_title),
            style = MaterialTheme.typography.headlineMedium,
        )
        Text(text = "Score : $displayedScore / ${questions.size}")
        if (isQuizFinished) {
            Text(text = "Quiz terminé")
            Button(onClick = {
                presenter.restart()
                displayedQuestionIndex = presenter.getCurrentQuestionIndex()
                isQuizFinished = presenter.isFinished()
                displayedScore = presenter.getScore()
            }) {
                Text(text = "Recommencer")
            }
        } else {
            Text(text = "Question ${displayedQuestionIndex + 1}")
            val question: Question = presenter.getCurrentQuestion()
            QuestionView(
                question = question,
                questionIndex = displayedQuestionIndex,
                presenter = presenter,
                onAnswerSubmitted = {
                    displayedScore = presenter.getScore()
                },
                onNextQuestion = {
                    presenter.goToNextQuestion()
                    displayedQuestionIndex = presenter.getCurrentQuestionIndex()
                    isQuizFinished = presenter.isFinished()
                },
            )
        }
    }
}

Aucun nouvel import n’est nécessaire. Chaque appel de QuestionView doit fournir onAnswerSubmitted en plus de onNextQuestion. Le bouton « Recommencer » n’est décrit que dans la branche de fin.

Quand l’écran quitte la fin, QuestionView est affichée de nouveau et retrouve son message initial. Le cadre remember lié au presenter et à l’indice conserve le fonctionnement vu à la page précédente.

07 / Tester une vraie partie

Prévois le total, puis compare.

  1. Lance une partie : le score commence à 0 / 4 et les choix de la première question sont activés.
  2. Question 1 : choisis Git. Le score devient 1 / 4 et les boutons de réponse se désactivent. Des clics supplémentaires ne doivent pas ajouter de point.
  3. Question 2 : choisis Button. Le score reste 1 / 4. Tu ne peux pas remplacer cette réponse par Text sur la même question.
  4. Questions 3 et 4 : choisis fun puis Boolean. À la fin, le total attendu est 3 / 4.
  5. Clique sur « Recommencer ». Vérifie la question 1, le score 0 / 4, le message initial, les choix activés et « Suivante » désactivé.
  6. Fais une deuxième partie avec d’autres réponses : son total ne doit pas contenir les points de la première.
